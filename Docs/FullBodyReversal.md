# 反转术式（三轴版）

和 `BodyReversal`（反转术式）同一套规则，唯一区别是交换时把 **Y 轴也一起换掉**：

- 释放条件相同：下半身落地、脚在启用的 `ReversalTile` 区域内，上半身在格子里不算资格。
- 按键相同：默认 F，按下边沿触发，按住不连放。
- 目标位置被实体占用时拒绝交换，显示提示，双方位置不变。
- 旋转和缩放各自保留，只有位置三轴互换。
- 下半身 → 上半身的 `(x, y, z)`；上半身 → 下半身的 `(x, y, z)`。

复用现有的 `ReversalTile`，**不需要修改任何现有脚本**。

## 和原版的区别

原版 `BodyReversal` 只换 X/Z，各留各的高度（代码注释里的原因是两个身体地面偏移不同，直接换 Y 会把胶囊埋进地里）。
本脚本就是按需求把这个限制去掉。如果两个格子在同一平面，两者效果看不出差别；只有两个身体不在同一高度时才有区别。

## 接线步骤

1. 打开 `Assets/Scenes/Whitebox1.unity`。
2. 选中下半身对象 `whiteboxplayer`。
3. Inspector → Add Component → 搜 `Full Body Reversal`。
4. 把 `Upper Body` 拖入上半身对象 `vision source`（它上面有 `VisionSource`）。
5. `Activation Key` 保持 F（想换键就改这里）。
6. 格子沿用场景里 `Reversal Tiles` 下已有的 `Reversal Tile`，不用新建。

注意：`FullBodyReversal` 和 `BodyReversal` **不要挂在同一个下半身上**，两个默认都用 F 会同时触发。只挂一个，或者把其中一个的 `Activation Key` 改成别的键。

## 高度落地（可选，默认关闭）

默认关闭时是严格的三轴交换：下半身直接落到上半身原来那个高度，可能悬空，也可能直接嵌进地面以下——这正是「连高度一起换」的原始行为。悬空的情况会由重力自然落下（`WhiteboxPlayerMovement` 每帧施加重力）；嵌进地面的情况 `CharacterController` 不一定能自己出来。

如果两个格子不在同一高度，建议打开 `Snap Lower Body To Ground`：

- 交换后从目标点向下投射找地面，把下半身放到实际地面上；
- 上半身仍然落到下半身原来的位置，不受影响。

| 字段 | 含义 |
|---|---|
| `Snap Lower Body To Ground` | 打开后按地面高度落位，关闭则严格按对方高度 |
| `Ground Probe Rise` | 向下投射的起点高度，从目标点往上多少米开始，默认 5 |
| `Ground Mask` | 哪些层算地面，默认全部层 |

## 已知边界

- 上半身的目标位置不做碰撞检查（和原版一致），因为 `vision source` 上没有碰撞体；如果以后换成带碰撞体的上半身，需要另外补检查。
- 落地计算假设下半身没有旋转。以后如果给下半身加旋转，落地高度会算歪。
- 上半身没有刚体也没有碰撞体，交换后它就停在新的位置上不动，视野射线以它自己的位置和 `sightHeight` 计算。
- `.meta` 文件交给 Unity 生成，不要手写。

## 怎么验证

1. 打开 `Whitebox1`，Play 后点击 Game 画面，等角色落地。
2. 把两个反转格子调成不同高度（或把上半身手动抬高），按 F：应该连高度一起交换。
3. 关掉 `Snap Lower Body To Ground` 再按一次，应该能明显看出"原样换高度"和"落到地面"的差别。
4. 走出格子边框后按 F 应无效；只把上半身放在格内也应无效；目标位置被墙挡住时应拒绝。
