# 反转术式

反转术式是下半身的技能。只有下半身落地且脚的位置处于启用的反转格子区域内，按 F 才能释放。
上半身位于格子内不会赋予下半身释放资格。技能只交换两个身体的 X/Z 坐标，各自保留 Y 高度、旋转和缩放。
目标位置有实体障碍时不交换，画面下方显示拒绝提示；成功后视野源随上半身的新位置更新。
按住 F 不会连续释放，需要松开再按。门仍使用 E。

## Whitebox1 接线

- `whiteboxplayer` 场景实例新增 `BodyReversal`，Upper Body 引用 `vision source` 的 `VisionSource`。
- `Reversal Tiles` 根对象下放置两个测试格子，水平中心分别为 `(0.93, 7.5)` 与 `(1.05, 1.05)`。
- 每个格子有 `ReversalTile` 与 BoxCollider；碰撞体勾选 Is Trigger，不阻挡移动或视线。
- 格子有边框和 `F / REVERSE` 文字。画面下方在可释放时显示按键提示。
- 玩家出生点在第一个格子内，等待落地后即可释放。上半身起点在第二个格子内，换过去后落地可再次释放。

## 编辑格子

在 Edit Mode 中展开 `Reversal Tiles`，选择一个完整的 `Reversal Tile`，用 Ctrl+D 复制，移动它的 X/Z。
不要只复制边框子对象。选中格子后可查看 BoxCollider 的触发范围；它同时限制水平范围与脚部高度。
调整 BoxCollider 尺寸后需要同步调整视觉边框。禁用格子对象或它的 BoxCollider 会停止授权技能。
格子应放在平坦、无实体障碍的可行走位置；此白盒实现保留各身体高度，不进行跨楼层落点调整。

## 实现范围

- `Assets/Scripts/BodyReversal.cs`：读取 F，检查下半身落地与格子范围、目标胶囊碰撞，交换位置。
- `Assets/Scripts/ReversalTile.cs`：注册启用格子，判断脚部是否处于盒体区域。
- `Assets/Scenes/Whitebox1.unity`：新增组件引用和测试格子。
- 未修改原有移动、门、视野脚本或共享玩家预制体；新增脚本的 .meta 由 Unity 生成。

## 验证与人工试玩

Unity 编辑器内已确认脚本编译无错误，场景检查无缺失脚本、无损坏预制体。
Play Mode 中调用实际技能方法验证：格内交换、各自高度保留、落地后换回、仅上半身在格内拒绝、
格子停用后拒绝、悬空拒绝、目标实体占用时拒绝且双方位置不变、CharacterController 恢复启用。

MCP 模拟键盘事件未能产生可用于验证的 F 按下边沿；2026-10-06 用户实际在 Game 画面按 F 试玩，确认上下半身发生交换。
按住不重复释放、松开后再次释放等实际键盘行为仍需人工检查，不计入本次用户确认结果。
人工步骤：打开 Whitebox1，Play 后点击 Game，等待出生点角色落地，按 F 应交换两者位置；
松开 F，等待下半身落地，再按 F 应换回；走出边框后按 F 应无效；仅把上半身放在格内也应无效。
