# TestLevel：寻光回廊 / Lumen Corridor

场景：`Assets/Scenes/TestLevel.unity`。

玩家从西南角出发，沿折返的回廊抵达东侧庭院中固定的 Vision Source。
场景只有一个 `WhiteboxPlayerMovement` 玩家和一个 `VisionSource`；使用项目现有的漫画渲染、视野遮挡、玻璃和碰撞烟雾。

## 操作与目标

- WASD：沿世界 X/Z 轴移动。W 对应画面上方，D 对应右方。
- R：随时回到起点，重置阶段、计时和通关状态。
- 进入光源周围 1.35 米内即通关，显示完成时间；点击 `PLAY AGAIN` 也可重新开始。
- 阶段标记用于反馈进度，不是必须触发的通关锁。
- 玩家上方的金色 `+` 是位置标记，在阴影内也可看到。

## 路线节奏

1. **玻璃通道**：起点 `(-9, -4.4)`，先向北走到 `z=4.2`，再绕过玻璃墙。玻璃允许光线通过，但阻挡角色。
2. **阴影折返**：从 `(-3.5, 4.2)` 向南走到 `z=-3.7`，从第一道实体墙下方穿过。
3. **内庭入口**：在 `(2.5, -3.7)` 向北折返到 `z=4.2`，绕过第二道实体墙上方，再向右进入庭院。光源位于 `(9, 0)`。

以上坐标均为水平 `(x, z)` 坐标。白色地面铺装标出推荐路线；其他开放地面也可以行走。
地面约 24 × 13.6 米，玩家速度 4.2 米/秒，不需要跳跃。熟悉路线后的完成时间约 10–15 秒，首次游玩可停下来观察遮挡和光路。

## 光路设计

三组 `VisionPortal` 只转送视野，不传送玩家，也不产生新的 Vision Source：

| 中继 | 光源庭院入口 | 回廊出口 | 用途 |
| --- | --- | --- | --- |
| A | 北侧 `(9, 5.4)` | 西南 `(-9.4, -5.8)` | 照亮起点和玻璃绕行 |
| B | 东侧 `(10.8, 0)` | 西侧上方 `(-3.5, 5.8)` | 照亮向南折返 |
| C | 西侧 `(7.4, 0)` | 中部下方 `(2.5, -5.8)` | 照亮向北折返 |

实体墙使用 `VisionObstacle` Layer/Tag，玻璃使用 Default Layer。光源半径为 27 米，采样射线数为 1024，最大传递跳数为 1。

## 编辑

场景根对象为 `L01 - Lumen Corridor`，下面按建筑、路线、光路、角色和 UI 分组。
墙体与地面采用 ProBuilder 网格，可直接在 Scene 中修改；网格和关卡材质位于 `Assets/Levels/TestLevel/`。
运行逻辑为 `LumenLevelFlow`，只作用于这个场景。角色移动和视野脚本、全局渲染配置保持现有实现。

`LumenLevelBuilder` 保存了初始搭建代码，菜单路径为 `Tools / Loongdum / TestLevel / Build Lumen Corridor`。
它要求 TestLevel 处于 Edit Mode，并会拒绝覆盖已经存在的关卡根对象。后续修改以已保存场景为准。

原始空场景的备份位于 `Temp/TestLevelDesign/TestLevel.before.unity`，Temp 目录会被 Unity 清理。
预览与通关截图位于 `Captures/TestLevel/`。
