## 玩法

WASD 连续移动；下半身落地且站在 F 格内按 F，交换双方 X/Z、保留各自高度；邻近拉杆按 E；R 重置。下半身不照亮场景。

1. 起点庭院 F①交换进入中央观察室。庭院与观察室之间只有实体玻璃观察窗，没有行走通路。
2. A 同时打开中央出口 D 和庭院出口 X。穿 D，向南走到东廊 F②。
3. F②把上半身留在东廊，下半身回到庭院的 F①位置。
4. 穿 X，向北踩住压力板1，打开东廊光闸 a，让上半身视线通过一对门户照到 B。离板关闸，已经辨认的 B → Y 提示保留；向南找 B，按 E 打开 Y。
5. 向北穿 Y，进入西控制室操作 C，打开北侧归廊 Z；沿归廊向东再向南，与上半身接近到 1.1 米内完成。完成后停止移动及技能，R 可重新开始。

关键机关顺序为 F① → A → F② → 踩1实际观察B → B → C → 汇合。开放区域中的走路路径不唯一。
X/D/Y/Z 单向开启；a 随踩板开启、离板关闭。E 不直接打开门，不存在全场开门组件。
B 的线路须先实际辨认，靠近未解锁的 B 会明确显示原因；A/C 不要求先看见其模型才能操作。所有拉杆均有文字接线标记、手柄动作和材质反馈。
